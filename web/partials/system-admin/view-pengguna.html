Daftar Penugasan Peran belum tersedia di API

Tab ini akan menampilkan peran + scope kelas/mata kuliah + status ACTIVE/SUSPENDED/REVOKED + masa berlaku, dengan aksi tangguhkan/cabut penugasan. API daftar penugasan dicatat sebagai tiket backend — UI tidak mengarang data dari roles[].

Undangan Ketua Murid (KM)

Undangan berlaku 7 hari, sekali pakai. Kirim ulang membatalkan token lama. Penerima tidak dapat mengubah peran/scope.

Daftar undangan belum tersedia di API

Tab ini akan menampilkan status PENDING/ACCEPTED/EXPIRED/REVOKED + kedaluwarsa + aksi kirim ulang/cabut. Daftar dicatat sebagai tiket backend.
