# Font lokal

Font ini dimuat dari `web/css/fonts.css` dan di-embed ke biner Go. Semua berkas memakai subset Latin, kecuali Material Symbols Outlined yang dibatasi pada nama ikon yang dipakai oleh HTML dan JavaScript (diperbarui 13 Oktober 2026: 91 ikon). Bila menambah ikon Material Symbols, perbarui subset font ini bersama pemakaiannya.

| Font | Sumber | Lisensi |
| --- | --- | --- |
| Poppins v24 | Google Fonts CSS2 / `fonts.gstatic.com` | [SIL OFL 1.1](OFL-Poppins.txt) |
| Montserrat v31 | Google Fonts CSS2 / `fonts.gstatic.com` | [SIL OFL 1.1](OFL-Montserrat.txt) |
| JetBrains Mono v24 | Google Fonts CSS2 / `fonts.gstatic.com` | [SIL OFL 1.1](OFL-JetBrains-Mono.txt) |
| Material Symbols Outlined v377 | Google Fonts CSS2 `icon_names` / `fonts.gstatic.com` | [Apache 2.0](LICENSE-Material-Symbols.txt) |
