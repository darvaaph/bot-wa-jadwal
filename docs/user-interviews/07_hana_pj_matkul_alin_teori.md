## 5. Intisari & Implikasi Desain (Key Takeaways)

1. **Mengurangi Kelelahan Mengingatkan Berulang Kali (*Reminder Fatigue*):**
   * Salah satu beban psikologis dan waktu terbesar PJ adalah harus mengingatkan teman sekelas berulang kali. Bot pengingat terjadwal otomatis (misal H-3, H-1, dan hari H batas pengumpulan) merupakan solusi kunci untuk membebaskan PJ dari tugas repetitif ini.
2. **Eliminasi Ketergantungan Menghafal Command (*Form-Driven Admin UI*):**
   * Hana menyoroti bahwa *command* teks bot sulit dihafalkan sehingga pemanfaatan bot menjadi tidak maksimal. Web dashboard dengan formulir terpandu yang berurutan (*step-by-step form*) menyelesaikan kendala ini sepenuhnya.
3. **Optimasi Kepadatan Pesan Siaran (*Concise Broadcast Layout*):**
   * Pesan bot yang terlalu panjang terbukti cepat tenggelam di chat WhatsApp. Format pesan di WhatsApp harus dibuat ringkas (hanya memuat nama matkul, judul tugas, deadline, dan link detail), bukan menumpahkan seluruh paragraf deskripsi di chat.
4. **Pentingnya Riwayat Perubahan (*Audit Trail / Change Log*):**
   * Untuk mengatasi kendala info yang berubah-ubah dari dosen, dashboard admin memerlukan pencatatan log/riwayat perubahan sehingga admin tahu riwayat modifikasi data sebelumnya.
5. **Form Sederhana dengan Integrasi Kalender Pemilihan Tanggal:**
   * Alur input yang paling disukai adalah formulir bertahap yang bersih dengan pemilih tanggal visual (*date-picker* / kalender) yang sekaligus memperlihatkan ketersediaan jadwal hari tersebut.
