## 5. Intisari & Implikasi Desain (Key Takeaways)

1. **Konsep Draf Jadwal (*Draft State / Staging Mode*):**
   * Masukan desain yang sangat unik dan solutif dari Giza: PJ seringkali menerima rencana perubahan jadwal tentatif dari dosen. Fitur draf memungkinkan PJ menyimpan perubahan di dashboard tanpa langsung mengirimkannya ke grup kelas. Setelah dosen memberikan lampu hijau final, PJ tinggal menekan tombol *publish*.
2. **Komponen Form Input Berbasis Dropdown (*Select/Dropdown Component*):**
   * Untuk input kelas, mata kuliah, dan slot jam, penggunaan menu *dropdown* jauh lebih disukai daripada kolom teks bebas (*free text*). Hal ini mempercepat input sekaligus mencegah kesalahan penulisan (*typo*).
3. **Meniadakan Format Command yang Kaku (*Eliminating Strict CLI Syntax*):**
   * Kendala terbesar bot lama adalah pengguna harus mematuhi format teks yang kaku. Penggantian mekanisme input dari chat WhatsApp ke formulir web visual akan mengeliminasi potensi kesalahan input manusia (*human error*).
4. **Optimalisasi Sistem Pengingat (*Automated Task Reminder*):**
   * Pengingat tugas otomatis adalah fitur yang paling dinantikan karena saat ini belum bekerja secara optimal, sehingga mahasiswa masih rawan terlewat deadline.
5. **Koordinasi Ruangan dan Tata Usaha (TU):**
   * Perubahan jadwal membutuhkan sinkronisasi dengan ketersediaan ruangan kampus dan konfirmasi TU.
