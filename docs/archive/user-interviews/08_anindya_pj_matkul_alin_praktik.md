## 5. Intisari & Implikasi Desain (Key Takeaways)

1. **Dukungan Penuh untuk Kelas Pengganti (*Makeup / Replacement Class Support*):**
   * Bot generasi sebelumnya hanya membaca jadwal reguler statis sehingga gagal menampilkan kelas pengganti. Sistem v2.0 harus mendukung entitas jadwal pengganti dinamis yang dapat terintegrasi ke broadcast harian bot.
2. **Interaksi Berbasis Kalender Interaktif (*Calendar Date-Click to Edit*):**
   * Responden menginginkan antarmuka kalender yang visual dan interaktif, di mana pengguna dapat menekan tanggal tertentu untuk melihat daftar agenda atau langsung mengedit detailnya.
3. **Mengatasi Kesulitan Menghafal Command (*No-CLI Requirement*):**
   * Pengguna mengeluhkan sulitnya mengingat sintaks teks command bot. Dashboard admin web berbasis antarmuka grafis (GUI) adalah solusi mutlak untuk membebaskan pengguna dari keharusan menghafal format perintah teks.
4. **Kebutuhan Ruangan Kosong untuk Manajemen Perkuliahan:**
   * Menegaskan kembali kebutuhan esensial: mencari ruangan kosong adalah salah satu kendala terbesar saat dosen meminta kuliah pengganti. Modul ketersediaan ruangan kampus menjadi fitur unggulan.
5. **Repositori Referensi Materi Terpusat (*Single Source of Truth*):**
   * Mengatasi perilaku mahasiswa yang terpaksa membuat catatan tugas terpisah dan mencari link tercecer di PPT/Teams/WA dengan menyediakan satu tempat terpusat untuk berkas materi dan tugas per mata kuliah.
